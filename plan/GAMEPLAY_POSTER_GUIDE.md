## 👁️ 4. SISTEM STEALTH & DETEKSI ZOMBIE

Zombie memiliki **Kerucut Penglihatan (Sight Cone)** dan kepekaan terhadap **Suara Langkah & Pintu (Noise Radius)**.

```
                     [ SUDUT PANDANG ZOMBIE (120° FOV) ]
                                      
                                     / \
                                    /   \      🔴 Jarak Bahaya (0 - 1.5m): INSTANT ATTACK!
                                   /  🔴 \     🟠 Jarak Kejar (1.5m - 7.0m): CHASE!
                                  /   🟠  \    🟡 Jarak Waspada (7.0m - 12.0m): ALERT
                                 /    🟡   \   
                                /     ⚪    \  ⚪ Di luar jangkauan: AMAN (IDLE)
                               [   🧟 ZOMBIE  ]
```

### 🔊 Tabel Tingkat Kebisingan (Noise Radii)

| Tindakan Pemain | Radius Kebisingan | Status Deteksi Zombie | Rekomendasi Taktik |
| :--- | :---: | :--- | :--- |
| **Jongkok (Crouch Walk)** | **0.9 meter** | 🟢 **Sangat Aman** | Dekati zombie dari belakang untuk *stealth injection*. |
| **Berjalan Biasa (Walk)** | **3.0 meter** | 🟡 **Waspada Ringan** | Aman jika di luar garis pandang langsung. |
| **Buka Pintu Perlahan** | **2.0 meter** | 🟡 **Waspada** | Buka pintu dari posisi jongkok. |
| **Buka Pintu Cepat / Tubruk** | **6.0 meter** | 🟠 **Mencurigakan** | Zombie sekitar akan berbalik mencari asal suara. |
| **Berlari (Sprint)** | **8.0 meter** | 🔴 **BAHAYA TINGGI** | Hanya gunakan saat kabur atau dalam keadaan darurat! |
| **Menyuntik Antidot** | **4.0 meter** | 🟡 **Suara Hiss Reaksi** | Pastikan tidak ada zombie lain di dekat target. |

### 🧠 Siklus Status AI Zombie (State Machine)
- 🟢 **IDLE**: Berdiri atau patroli santai. Pandangan lurus ke depan.
- 🟡 **ALERT (Kuning)**: Mendengar suara atau melihat sekilas. Zombie akan menoleh lambat ke arah suara (1.5 detik toleransi).
- 🟠 **SEARCH (Oranye)**: Mencari lokasi terakhir pemain terlihat selama 4–8 detik sebelum kembali tenang.
- 🔴 **CHASE (Merah)**: Mengejar pemain dengan kecepatan penuh.
- 💥 **ATTACK (Merah Menyala)**: Menyerang pemain saat jarak < 1.5m (Cooldown serangan 1.5s).
- 💫 **STUNNED**: Terkena stun (tembakan atau jebakan pintu), waktu paling aman untuk menyuntik!
